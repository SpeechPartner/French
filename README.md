# SpeechPartner.French

Een gratis, offline werkende app (PWA) om Frans te gebruiken in gesprekken. Geen account, geen server, geen kosten.

Deze map is een complete app. Zet de **inhoud** van deze map in een eigen GitHub-repository (bijvoorbeeld `French`) en zet GitHub Pages aan.
Webadres: https://speechpartner.github.io/French/
Gebruik niet de repository van de Spaanse app: elke taal heeft zijn eigen repository en zijn eigen webadres.

Versie 2.1
